# Automated Multi-Tier Web Application Hosting System

A real-time cloud hosting management dashboard designed to demonstrate multi-tier application hosting, load balancing, auto-scaling, server monitoring, database access control, and deployment management.

## 🌐 Live Demo

**Live Website:** https://automated-multi-tier-web-hosting.onrender.com

**GitHub Repository:** https://github.com/Padmavati2611/Automated-Multi-Tier-Web-Hosting

## 📌 Project Overview

The Automated Multi-Tier Web Application Hosting System is a web-based cloud infrastructure management platform. It provides a centralized dashboard to monitor server instances, visualize traffic, manage scaling policies, and observe system performance in real time.

The project demonstrates how different hosting layers and infrastructure management concepts can work together in a single application.

## ✨ Key Features

- **Load Balancing:** Distributes incoming traffic across healthy compute instances.
- **Auto Scaling:** Dynamically adjusts server capacity based on resource utilization.
- **Real-Time Monitoring:** Displays live system telemetry and server status.
- **Server Management:** Add, remove, and monitor server instances.
- **Traffic Simulation:** Simulates incoming traffic and workload changes.
- **Database Security:** Demonstrates database access policies and access testing.
- **Deployment Management:** Provides deployment controls and activity monitoring.
- **Google Authentication:** Secures dashboard access through Firebase Authentication.
- **Live Updates:** Uses Server-Sent Events (SSE) for real-time data streaming.

## 🏗️ System Architecture

The application follows a multi-tier architecture:

1. **Presentation Layer:** Provides the interactive dashboard and user interface.
2. **Application Layer:** Handles API requests, traffic management, scaling, and server operations.
3. **Data Layer:** Handles database connectivity, storage, and access policies.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Git
- Visual Studio Code

### Step 1: Clone the Repository

```bash
git clone https://github.com/Padmavati2611/Automated-Multi-Tier-Web-Hosting.git
```

### Step 2: Open the Project

```bash
cd Automated-Multi-Tier-Web-Hosting
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Application

```bash
npm run dev
```

Open the local application at:

```text
http://localhost:3000
```

### Step 5: Build for Production

```bash
npm run build
```

## 🚀 Deployment

The application can be deployed using cloud hosting platforms such as Render and Vercel.

- **Render:** Hosts the Node.js application.
- **Vercel:** Can be used to host the frontend separately.
- **Firebase:** Provides Google authentication.

For a separate frontend and backend deployment, configure the frontend API base URL to point to the deployed backend.
